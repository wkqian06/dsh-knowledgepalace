# A multi-species synthesis of physiological mechanisms in drought-induced tree mortality

## Summary

本文综合多树种干旱致死生理机制的证据，核心问题是：树木在干旱致死时，水力失效与碳饥饿各自有多普遍？作者汇集 19 项实验与观测研究、26 个树种、34 个"研究×物种"案例，用统一框架把 PLC（木质部导水率丧失百分比）与相对对照的 NSC（非结构性碳水化合物）偏差作为两类机制的指标。由于各研究设计差异过大，分析限于逐案例"死亡木 vs 存活/对照木"的检验，而非统计元分析。结果显示：所有有 PLC 数据的案例死亡时 PLC ≥60%（均值 84.3%，逐案例显著高于对照），而 NSC 显著降低仅见于 48% 的案例和 38% 的物种，且裸子植物明显多于被子植物。作者据此主张水力失效是普遍成分、碳饥饿并非普适，二者不构成互斥二分，并把持续 ≥60% 的 PLC 作为植被模型死亡率阈值的建模起点。边界：树种仅 26 个且材料以幼苗/盆栽为主，原研究设计无法区分死亡原因与死亡症状，致死 PLC 阈值与 NSC 阈值均未确定。

## Limitations & gaps

- 树种代表性不足：仅 26 个物种，热带树种尤其缺失，作者自陈无法代表全球森林树种多样性（C5, C33）。
- 材料偏倚：数据以幼苗、幼树和盆栽为主，根体积受限可能使植株更快死于水力失效，从而高估水力路径的普遍性（C30）。
- 生活史覆盖不足：仅 3 个物种有跨尺寸/个体发育的死亡数据，且这些物种内部的 NSC 与 PLC 响应一致性并不稳定（C31）。
- 因果推断受限：纳入研究多未设计区分死亡驱动因子与濒死症状，作者明确表示无法判定 NSC/PLC 变化是致死原因还是死亡过程的结果（C23, C24）。
- 阈值未定：致死 PLC 阈值未被专门量化，持续时间与强度未知（C19）；NSC 阈值随树种、个体发育、组织、冠层位置、季节、环境与生物互作而变（C26），且受 NSC 储存调控机制认识不足所限（C25）。
- 方法学不确定：NSC 绝对浓度因标准、方法学与实验室协议差异而跨研究不可比（C43），只能使用案例内相对差异（C36）；水力测量与脆弱性曲线存在人为假象风险，作者无法排除（C38）；性状数据部分缺失（3 个物种无水力性状）并受 TRY 许可限制（C39）。
- 统计推断限制：逐案例检验、未合并效应量，也没有跨案例的不确定性量化（C6, C40）；作者未报告多重比较校正（system-inferred，属系统阅读判断而非作者陈述）。
- 性状结论脆弱：裸子植物"栓塞抗性–NSC"关系受 Callitris rhomboidea 强烈影响（C29），图注称剔除该点后仍 p<0.01，但需回补充材料核对。
- 无对应 gap 卡：本卡 gaps 字段为空；上述"跨物种机制合成与阈值量化"缺口可作为候选 gap 卡（system-inferred）。
