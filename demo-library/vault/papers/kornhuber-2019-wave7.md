# Extreme weather events in early summer 2018 connected by a recurrent hemispheric wave-7 pattern

## Summary

表明 2018 年夏季北美、西欧与里海地区的热浪及欧洲东南部、日本的强降水，有一部分由放大的半球尺度 7 波环流型相连；该型也出现在 2003、2006、2015 年的欧洲热浪中，且近几十年出现频率上升。仅读到摘要。
