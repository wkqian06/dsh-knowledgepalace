# Robust Responses of the Hydrological Cycle to Global Warming

## Summary

基于 IPCC 第四次评估的气候变化试验，梳理水文循环中各模式一致的响应：对流质量通量减弱、水平水汽输送增强、蒸发减降水格局增强，以及中高纬显热输送的变化。作者把这些稳健响应都归结为低层大气水汽增加。本卡片仅读到摘要，诊断细节与模式差异需读全文。
