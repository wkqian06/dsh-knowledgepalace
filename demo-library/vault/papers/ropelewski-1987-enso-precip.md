# Global and Regional Scale Precipitation Patterns Associated with the El Niño/Southern Oscillation

## Summary

用 1700 多个站点的月降水，在全球框架下识别与 ENSO 空间一致的降水区域及其相位，并统计这些关系实际与 ENSO 同现的比例。仅读到摘要，各区域的幅度与统计细节需读全文。
